📌 Project Overview

EduVision – Higher Education Performance Dashboard is a data visualization and analytics project designed to analyze and compare the performance of higher education institutions across different countries and regions.

The project uses university ranking, research, student, and country-level data to generate meaningful insights through interactive dashboards.

---

🎯 Objectives

- Analyze global university ranking performance.
- Compare universities and countries based on ranking scores.
- Visualize research performance using available research indicators.
- Analyze student-related indicators such as international student percentage and faculty-to-student ratio.
- Compare educational performance across countries and regions.
- Build interactive and user-friendly dashboards using Tableau.
