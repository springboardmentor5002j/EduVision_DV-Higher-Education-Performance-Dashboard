\# EduVision DV – Higher Education Performance Dashboard



\## Project Overview



EduVision DV is an interactive Tableau dashboard designed to analyze higher education performance and university rankings.



The dashboard provides insights into university performance, research analytics, student diversity, international students, and country-level comparisons.



\## Dashboard Sections



\- Home

\- Overview

\- Research

\- Student

\- Country



\## Key Visualizations



\- Top Performing Countries

\- Regional Education Benchmarking

\- Top 10 Universities by Global Ranking Score

\- Country Ranking Comparison

\- Research Analytics

\- International Students by Region

\- Student Diversity Trends

\- Faculty-to-Student Ratio



\## Tools Used



\- Tableau

\- Data Visualization

\- Data Cleaning

\- Data Analysis

\- GitHub



\## Dataset



The project uses university and higher-education ranking data for analysis and visualization.



\## Objective



The main objective of this project is to transform higher education data into meaningful interactive visualizations that help users understand university performance, research activity, student trends, and regional differences.
